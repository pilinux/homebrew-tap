# Pilinux Tap

## How do I install these formulae?

`brew install pilinux/tap/<formula>`

Or `brew tap pilinux/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "pilinux/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
